# Chewie-Tracker

Personal health tracker for my cat Chewie.

Chewie has diagnosed hypothyroidism. The app logs symptoms, treatments, and notes so patterns are visible over time — including symptoms no vet has been able to pin to a second diagnosis yet.

**Live:** https://idahofidelity.github.io/Chewie-Tracker/

## Stack

Single-page HTML app, GitHub Pages. No backend; data stays in the browser.

## Why it exists

A real patient (a cat) with incomplete answers. Same discipline as the civic trackers: structured logs, dates, and treatments — not memory.
